# 238. 除自身以外数组的乘积 - 题解

## 题目描述

给你一个整数数组 `nums`，返回数组 `answer`，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积。

题目数据保证数组 `nums` 之中任意元素的全部前缀元素和后缀的乘积都在 32 位整数范围内。

请不要使用除法，且在 O(n) 时间复杂度内完成此题。

---

## 思路一：暴力法

**核心思想**：对每个位置 `i`，遍历数组中除了 `i` 以外的所有元素，计算它们的乘积。

**算法流程**：
1. 外层循环遍历每个位置 `i`
2. 内层循环遍历所有位置 `j`（`j ≠ i`），计算乘积
3. 将乘积存入 `output[i]`

**代码实现**：
```cpp
class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        int n = nums.size();
        vector<int> output(n, 1);

        for (int i = 0; i < n; i++) {
            int product = 1;
            for (int j = 0; j < n; j++) {
                if (j != i) {
                    product *= nums[j];
                }
            }
            output[i] = product;
        }

        return output;
    }
};
```

**复杂度分析**：
- 时间复杂度：O(n²) —— 两层嵌套循环
- 空间复杂度：O(1) —— 除输出数组外，只用了常数空间

**问题**：存在大量重复计算，时间复杂度过高。

---

## 思路二：输入预处理（减少重复的计算）

**核心思想**：利用重复计算，预处理前缀积和后缀积。

`output[i] = pre[i] * post[i]`
- `pre[i]`：位置 `i` 左边所有数的乘积
- `post[i]`：位置 `i` 右边所有数的乘积

**算法流程**：
1. 第一次遍历：计算 `pre[]` 数组
2. 第二次遍历：计算 `post[]` 数组
3. 第三次遍历：计算 `output[i] = pre[i] * post[i]`

**代码实现**：
```cpp
class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        int n = nums.size();
        vector<int> pre(n, 1);
        vector<int> post(n, 1);
        vector<int> output(n);

        // 计算前缀积
        for (int i = 1; i < n; i++) {
            pre[i] = pre[i - 1] * nums[i - 1];
        }

        // 计算后缀积
        for (int i = n - 2; i >= 0; i--) {
            post[i] = post[i + 1] * nums[i + 1];
        }

        // 计算最终结果
        for (int i = 0; i < n; i++) {
            output[i] = pre[i] * post[i];
        }

        return output;
    }
};
```

**复杂度分析**：
- 时间复杂度：O(3n) —— 三次线性遍历
- 空间复杂度：O(2n) —— 额外使用了 `pre[]` 和 `post[]` 数组

**优化方向**：能否减少空间使用？

## 思路三： 滚动更新  前/后缀积 （使用除法）

**核心思想**：先计算所有数的总乘积，然后对每个位置 `i`，用总乘积除以 `nums[i]`。

**算法流程**：
1. 第一次遍历：计算所有数的乘积 `total_product`
2. 第二次遍历：对每个位置 `i`，`output[i] = total_product / nums[i]`

**代码实现**：
```cpp
class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        int n = nums.size();
        int total_product = 1;
        int zero_count = 0;

        // 计算总乘积，统计 0 的个数
        for (int num : nums) {
            if (num == 0) {
                zero_count++;
            } else {
                total_product *= num;
            }
        }

        vector<int> output(n);

        // 根据零的个数处理
        for (int i = 0; i < n; i++) {
            if (zero_count == 0) {
                output[i] = total_product / nums[i];
            } else if (zero_count == 1) {
                output[i] = (nums[i] == 0) ? total_product : 0;
            } else {
                output[i] = 0;
            }
        }

        return output;
    }
};
```

**复杂度分析**：
- 时间复杂度：O(2n) —— 两次线性遍历
- 空间复杂度：O(1) —— 只用了常数个变量

**问题**：题目明确要求**不能使用除法**，所以这个思路虽然简洁，但不符合题目要求。

## 思路四：分两次遍历 前/后缀积 并使用  output[]  作为临时存储

**核心思想**：利用输出数组 `output[]` 存储前缀积，再用一个滚动变量计算后缀积。

**关键优化**：
- 不额外开 `pre[]` 数组，直接用 `output[]` 存前缀积
- 不开 `post[]` 数组，用 `post_mult` 滚动变量

**算法流程**：
1. 第一次遍历（左→右）：计算前缀积，存入 `output[]`
2. 第二次遍历（右→左）：用 `post_mult` 累积后缀积，边遍历边更新 `output[]`

**代码实现**：
```cpp
class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        int n = nums.size();
        vector<int> output(n, 1);

        // 第一次遍历：计算前缀积，存储在 output 中
        int pre_mult = 1;
        for (int i = 0; i < n; i++) {
            output[i] = pre_mult;
            pre_mult *= nums[i];
        }

        // 第二次遍历：计算后缀积，并乘到 output 中
        int post_mult = 1;
        for (int i = n - 1; i >= 0; i--) {
            output[i] *= post_mult;
            post_mult *= nums[i];
        }

        return output;
    }
};
```

**复杂度分析**：
- 时间复杂度：O(n) —— 两次线性遍历
- 空间复杂度：O(1) —— 除输出数组外，只用了两个变量 `pre_mult` 和 `post_mult`

**注意**：题目说明输出数组不算空间复杂度，所以这是最优空间方案，且符合题目"不使用除法"的要求。

## 总结对比

| 思路 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 暴力法 | O(n²) | O(1) | 简单但低效 |
| 输入预处理 | O(3n) | O(2n) | 易理解，空间稍大 |
| 滚动更新（除法） | O(2n) | O(1) | 简洁但违反题目要求 |
| 两次遍历滚动更新 | O(2n) | O(1) | **最优解** |

---

## 关键要点

1. **避免重复计算**：前缀积和后缀积的思想是预处理常用技巧
2. **空间优化**：利用输出数组存储中间结果，减少额外空间
3. **滚动变量**：用变量代替数组，将 O(n) 空间降到 O(1)
4. **遵循题目约束**：除法虽然简洁，但题目明确禁止使用

---

**推荐**：面试中使用**思路四**，代码简洁、效率最优、符合题目要求。
