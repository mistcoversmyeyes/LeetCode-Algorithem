# 105. 从前序与中序遍历序列构造二叉树

难度：中等

标签：树，数组，哈希表，分治，二叉树

---

## 题目描述

给定两个整数数组 `preorder` 和 `inorder`，其中 `preorder` 是二叉树的**先序遍历**，`inorder` 是同一棵树的**中序遍历**，请构造二叉树并返回其根节点。

**示例 1：**
```
输入: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
输出: [3,9,20,null,null,15,7]
```

**示例 2：**
```
输入: preorder = [-1], inorder = [-1]
输出: [-1]
```

**提示：**
- `1 <= preorder.length <= 3000`
- `inorder.length == preorder.length`
- `-3000 <= preorder[i], inorder[i] <= 3000`
- `preorder` 和 `inorder` 均无重复元素
- `inorder` 保证是二叉树的中序遍历序列
- `preorder` 保证是二叉树的先序遍历序列

---

# 思路一：递归分治

## 解题思路

**核心思想**：利用前序遍历和中序遍历的特性，通过根节点位置将问题分解为左右子树的子问题。

**前序遍历特性**：第一个元素就是根节点
**中序遍历特性**：根节点左侧是左子树，右侧是右子树

这是我最自然的想法：先通过 preorder 找到根节点，然后根据 inorder 数组获取左子树和右子树的元素个数，进而获取左子树和右子树的 preorder 和 inorder 遍历结果，然后递归调用解决。

**脑内模拟验证**（这个步骤很重要！）：

以 `preorder = [3,9,20,15,7]`, `inorder = [9,3,15,20,7]` 为例：

**第一轮递归：**
- 根节点 = preorder[0] = 3
- 在 inorder 中找到 3 的索引 = 1
- 左子树元素个数 = 1，右子树元素个数 = 3

**第二轮递归（左子树）：**
- 左子树 preorder：[9]
- 左子树 inorder：[9]

**第二轮递归（右子树）：**
- 右子树 preorder：[20, 15, 7]
- 右子树 inorder：[15, 20, 7]

**算法流程：**
1. 用 preorder 的第一个元素创建根节点
2. 在 inorder 中找到根节点的位置 `root_index`
3. 计算左子树大小：`left_size = root_index - in_left`
4. 递归构建左子树
5. 递归构建右子树
6. 返回根节点

## 复杂度

- **时间复杂度**：O(n²)
  - 每个节点需要在 inorder 中线性查找，O(n)
  - 共 n 个节点，总共 O(n²)
- **空间复杂度**：O(n)
  - 递归栈深度 O(n)
  - 节点空间 O(n)

## Code

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
  TreeNode *buildTree(vector<int> &preorder, vector<int> &inorder) {
    TreeNode* head = new TreeNode();
    return buildTree_recur(head, preorder, inorder, 0, preorder.size() - 1, 0, inorder.size() - 1);
  }

  TreeNode *buildTree_recur(TreeNode *head, vector<int> &preorder,
                            vector<int> &inorder, int pre_left, int pre_right,
                            int in_left, int in_right) {
    // 边界条件：空区间返回空树
    if (pre_right < pre_left || in_right < in_left) {
        delete head;  // 防止内存泄漏
        return nullptr;
    }

    // preorder 第一个元素是根节点
    head->val = preorder[pre_left];

    // 在 inorder 中找到根节点的位置
    int root_index = in_left;
    while (inorder[root_index] != head->val) {
        root_index++;
    }

    // 计算左子树大小
    int left_size = root_index - in_left;

    // 递归构建左子树
    int new_pre_left = pre_left + 1;
    int new_pre_right = pre_left + left_size;
    int new_in_left = in_left;
    int new_in_right = root_index - 1;
    head->left = buildTree_recur(new TreeNode(), preorder, inorder, new_pre_left, new_pre_right,
                    new_in_left, new_in_right);

    // 递归构建右子树
    new_pre_left = pre_left + left_size + 1;
    new_pre_right = pre_right;
    new_in_left = root_index + 1;
    new_in_right = in_right;
    head->right = buildTree_recur(new TreeNode(), preorder, inorder, new_pre_left, new_pre_right,
                    new_in_left, new_in_right);

    return head;
  }
};
```

**问题/优化方向**：
- 每次递归都要在 inorder 中线性查找根节点，可以用哈希表优化到 O(1)

# 思路二：哈希表优化查找

## 解题思路

**核心思想**：用哈希表预处理，将 inorder 的 `value → index` 映射存起来，查找从 O(n) 降到 O(1)。

这是在思路一的基础上的优化：我一开始认为"由于子树是不断缩小的，线性查找的复杂度也不是很高"，但经过分析发现：

- 每个节点在 inorder 中查找一次，O(n)
- 共有 n 个节点
- 总查找复杂度：O(n²)

用哈希表可以：
- 预处理 O(n)
- 每次查找 O(1)
- 总体从 O(n²) 降到 O(n)

**算法流程**：
1. 用 `unordered_map` 存储 `inorder[i] → i` 的映射
2. 递归过程与思路一相同，但查找根节点位置时直接查哈希表

## 复杂度

- **时间复杂度**：O(n)
  - 哈希表预处理 O(n)
  - 每次查找 O(1)，总共 n 次查找
- **空间复杂度**：O(n)
  - 哈希表空间 O(n)
  - 递归栈 O(n)
  - 节点空间 O(n)

## Code

```cpp
class Solution {
private:
    unordered_map<int, int> index_map;  // val → inorder index

    TreeNode* build(vector<int>& preorder, vector<int>& inorder,
                     int pre_left, int pre_right,
                     int in_left, int in_right) {
        if (pre_left > pre_right) {
            return nullptr;
        }

        // 前序遍历第一个节点是根节点
        int root_val = preorder[pre_left];
        TreeNode* root = new TreeNode(root_val);

        // 在中序遍历中找到根节点位置（O(1) 查找）
        int root_index = index_map[root_val];

        // 左子树大小
        int left_size = root_index - in_left;

        // 递归构建左子树
        root->left = build(preorder, inorder,
                           pre_left + 1, pre_left + left_size,
                           in_left, root_index - 1);

        // 递归构建右子树
        root->right = build(preorder, inorder,
                            pre_left + left_size + 1, pre_right,
                            root_index + 1, in_right);

        return root;
    }

public:
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        // 预处理：构建 value → index 的哈希表
        for (int i = 0; i < inorder.size(); i++) {
            index_map[inorder[i]] = i;
        }

        return build(preorder, inorder, 0, preorder.size() - 1, 0, inorder.size() - 1);
    }
};
```

# 总结对比

| 思路 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 递归分治 | O(n²) | O(n) | 实现简单，适合面试快速写出 |
| 哈希表优化 | O(n) | O(n) | 用额外空间换时间，是更优解 |

# 关键词与核心洞察

## 关键词
- **分治**：将大问题分解为左右子树的子问题，递归解决
- **递归边界**：`pre_left > pre_right` 表示空区间，返回 `nullptr`
- **索引计算**：通过 inorder 中的根节点位置计算左右子树的索引范围

## 核心洞察
- **两种遍历的组合威力**：单独看 preorder 或 inorder 都无法确定树的结构，但两者结合可以唯一确定二叉树
- **preorder 定根**：第一个元素永远是根节点
- **inorder 分界**：根节点位置将数组分为左右子树
- **索引而非切片**：用索引范围代替数组切片，避免 O(n) 的拷贝开销

## 易错点
1. **边界条件写反**：容易写成 `in_left < in_right`，应该是 `in_right < in_left` 或 `pre_left > pre_right`
2. **索引计算错误**：右子树的 pre_left = `pre_left + left_size + 1`，注意 `+1`
3. **内存泄漏**：如果先 `new TreeNode()` 再发现是空树，需要 `delete`
