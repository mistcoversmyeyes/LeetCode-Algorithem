**206.** 反转链表 - 题解
====

# 题目描述

给你单链表的头节点 `head` ，请你反转链表，并返回反转后的链表。

**示例 1：**
```
输入：head = [1,2,3,4,5]
输出：[5,4,3,2,1]
```

**示例 2：**
```
输入：head = [1,2]
输出：[2,1]
```

**示例 3：**
```
输入：head = []
输出：[]
```

---

# 思路一：迭代法（✅ 推荐解法）

## 解题思路

**核心思想**：用三个指针，逐个反转节点的指向。

**算法流程**：
1. 初始化：`pre = nullptr`（已反转部分的头），`cur = head`（待处理节点）
2. 遍历链表，每次迭代：
   - 保存 `cur->next` 到临时变量
   - 反转：`cur->next = pre`
   - 前移：`pre = cur`, `cur = next`
3. 当 `cur` 为空时，`pre` 就是新链表的头

## 复杂度
- 时间复杂度：O(n) —— 遍历一次链表
- 空间复杂度：O(1) —— 只用了三个指针

## Code
```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* pre = nullptr;  // 已反转部分的头节点
        ListNode* cur = head;     // 待处理的节点
        while (cur) {
            ListNode* next = cur->next;  // 保存下一个节点
            cur->next = pre;             // 反转指向
            pre = cur;                   // pre 前移
            cur = next;                  // cur 前移
        }
        return pre;  // pre 指向新链表的头
    }
};
```

# 思路二：递归法

## 解题思路

**核心思想**：先递归到链表末尾，然后在回溯过程中反转节点。

**算法流程**：
1. 递归终止条件：`head == nullptr` 或 `head->next == nullptr`
2. 递归反转后续链表，得到新的头节点 `new_head`
3. 回溯时反转：让 `head->next->next` 指回 `head`，`head->next` 置空

## 复杂度
- 时间复杂度：O(n) —— 每个节点处理一次
- 空间复杂度：O(n) —— 递归调用栈

## Code
```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        // 递归终止条件
        if (head == nullptr || head->next == nullptr) {
            return head;
        }

        // 递归反转后续链表
        ListNode* new_head = reverseList(head->next);

        // 回溯时反转
        head->next->next = head;
        head->next = nullptr;

        return new_head;
    }
};
```

**问题/优化方向**：
递归解法简洁但使用了 O(n) 的栈空间，面试中更推荐迭代法。

# 总结对比

| 思路 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 迭代法 | O(n) | O(1) | 最优解，推荐 |
| 递归法 | O(n) | O(n) | 代码简洁，但空间换时间 |

# 关键词与核心洞察

## 关键词
- **循环不变量**：每次迭代开始时，`pre` 指向已反转链表的头，`cur` 指向待处理节点。这个不变量是理解迭代法的核心。
- **虚拟头节点（哨兵节点）**：用于消除头节点特殊性的技巧。但本题中不需要 —— `nullptr` 本身就是完美的初始"已反转链表"。

## Insight
- **迭代法的本质**：维护两个区域 —— 已反转区域（`pre` 及其之前）和未反转区域（`cur` 及其之后）。每次迭代把 `cur` 从未反转区域"摘下来"挂到已反转区域前面。
- **为什么不需要虚拟头节点**：反转链表不会"删除"头节点，只是把它变成尾节点。头节点的变换是算法的自然结果，`nullptr` 作为初始 `pre` 让空链表和一般情况完全统一，没有特殊情况。

## 易错点
- **指针丢失**：必须先用 `next` 保存 `cur->next`，否则修改 `cur->next` 后就找不到后续节点了。
- **虚拟头节点的误用**：最初尝试用了 `psedo_head`，但实际上 `pre` 直接初始化为 `nullptr` 即可，多余的哨兵节点不仅无用，还可能引入内存管理问题。

---

**推荐**：面试中使用**迭代法**，O(1) 空间复杂度是最优解，且容易理解和实现。
