**3212.** 统计 X 和 Y 频数相等的子矩阵数量 - 题解
====

# 题目描述

给你一个二维字符矩阵 `grid`，其中 `grid[i][j]` 可能是 `'X'`、`'Y'` 或 `'.'`，返回满足以下条件的子矩阵数量：

- 包含 `grid[0][0]`
- `'X'` 和 `'Y'` 的频数相等。
- 至少包含一个 `'X'`。

---

# 思路一：二维前缀和

## 解题思路

**核心思想**：用 DP 预处理每个位置到 `(0,0)` 的子矩阵中 X 和 Y 的频数，然后遍历所有位置统计满足条件的子矩阵。

这是我最自然的想法：题目要求子矩阵必须包含 `grid[0][0]`，所以本质上是求所有以 `(0,0)` 为左上角、`(i,j)` 为右下角的子矩阵。

**定义状态**：`dp[i][j]` 表示从 `(0,0)` 到 `(i,j)` 的子矩阵中 X 和 Y 的频数 `{fre_x, fre_y}`。

**递推公式**：这是二维前缀和的标准公式。

我意识到了递推关系：

```
dp[i][j] = dp[i-1][j] + dp[i][j-1] - dp[i-1][j-1]
```

但我一开始写的时候漏掉了**当前格子本身的贡献**。正确的公式应该是：

```
dp[i][j] = dp[i-1][j] + dp[i][j-1] - dp[i-1][j-1] + to_fre_pair(grid[i][j])
```

**算法流程**：

1. 处理边界情况：
   - `dp[0][0]`：直接赋值
   - 第一列 `dp[i][0]`：只能从上方累加
   - 第一行 `dp[0][j]`：只能从左方累加

2. 双层循环填充中间位置：
   - 应用递推公式计算 `dp[i][j]`

3. 每次填充后检查条件：
   - `x > 0`（至少一个 X）
   - `x == y`（频数相等）

## 复杂度
- 时间复杂度：O(m × n)
- 空间复杂度：O(m × n)

## Code
```cpp
class Solution {
public:
    int m, n;

    // 过程抽象：字符转频数对
    pair<int, int> to_fre_pair(char c) {
        if (c == 'X') return {1, 0};
        else if (c == 'Y') return {0, 1};
        else return {0, 0};
    }

    // 过程抽象：频数对相加
    pair<int, int> add(pair<int, int> a, pair<int, int> b) {
        return {a.first + b.first, a.second + b.second};
    }

    // 过程抽象：频数对相减
    pair<int, int> sub(pair<int, int> a, pair<int, int> b) {
        return {a.first - b.first, a.second - b.second};
    }

    // 过程抽象：验证条件并计数
    void validate_and_inc(pair<int, int> a, int& cnt) {
        if (a.first > 0 && a.first == a.second) {
            cnt++;
        }
    }

    int numberOfSubmatrices(vector<vector<char>>& grid) {
        int cnt = 0;

        // 数据抽象：dp[i][j] 表示 (0,0) 到 (i,j) 的子矩阵中 X/Y 的频数
        m = grid.size();
        n = grid[0].size();
        auto dp = vector<vector<pair<int, int>>>(m, vector<pair<int, int>>(n, {0, 0}));

        // 初始化 (0,0)
        dp[0][0] = to_fre_pair(grid[0][0]);
        validate_and_inc(dp[0][0], cnt);

        // 填充第一列
        for (int i = 1; i < m; i++) {
            dp[i][0] = add(dp[i - 1][0], to_fre_pair(grid[i][0]));
            validate_and_inc(dp[i][0], cnt);
        }

        // 填充第一行
        for (int j = 1; j < n; j++) {
            dp[0][j] = add(dp[0][j - 1], to_fre_pair(grid[0][j]));
            validate_and_inc(dp[0][j], cnt);
        }

        // 填充中间位置
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                // 关键：别忘了当前格子的贡献！
                dp[i][j] = add(sub(dp[i - 1][j], dp[i - 1][j - 1]), dp[i][j - 1]);
                dp[i][j] = add(dp[i][j], to_fre_pair(grid[i][j]));
                validate_and_inc(dp[i][j], cnt);
            }
        }

        return cnt;
    }
};
```

# 关键词与核心洞察

## 关键词
- **二维前缀和**：用于快速计算矩形区域内元素的累计值，核心思想是容斥原理
- **数据抽象**：用 `pair<int,int>` 表示频数，封装 X 和 Y 的计数
- **过程抽象**：`add`、`sub`、`to_fre_pair`、`validate_and_inc` 等辅助函数，让主逻辑更清晰

## Insight

**关于数据抽象和过程抽象**：

SICP 中以 rational number 为例讲解了数据抽象的本质 —— 用户只需要知道接口，不需要知道底层实现。

本题中，我用 `pair<int,int>` 作为 Count 的实现，这是"偷了个懒"。最优美的解法应该是先实现一个 `Count` 类：

```cpp
struct Count {
    int x, y;
    Count operator+(const Count& other) const { return {x + other.x, y + other.y}; }
    Count operator-(const Count& other) const { return {x - other.x, y - other.y}; }
    bool valid() const { return x > 0 && x == y; }
};
```

这样使用者不需要知道内部是 `{x, y}` 还是 `{y, x}` 还是其他表示，实现者也可以自由更换底层结构。

**关于 DP 的本质**：

DP = DAG + 拓扑序。想出 subproblem 的 relation 以后，剩下的就是根据脑海中想象出来的那个 DAG，按拓扑排序的顺序填充 DP 数组。

```
dp[i-1][j-1] → dp[i-1][j]
      ↓            ↓
dp[i][j-1]  →  dp[i][j]
```

## 易错点

1. **漏掉当前格子的贡献**：递推公式 `dp[i-1][j] + dp[i][j-1] - dp[i-1][j-1]` 漏掉了 `grid[i][j]` 本身，正确的公式需要加上 `to_fre_pair(grid[i][j])`

2. **边界条件的索引**：
   - 填充第一行时：`dp[0][j] = add(dp[0][j-1], ...)` 不是 `dp[j-1][0]`
   - 填充第一列时：`dp[i][0] = add(dp[i-1][0], ...)`

3. **忘记检查 `dp[0][0]`**：初始化后也要检查是否满足条件

4. **拼写错误**：`validate` 不是 `vaildate`

---

**推荐**：面试中使用**二维前缀和**，思路清晰，一次遍历完成。重点说清楚四种情况的递推公式和填充顺序。
