# [1980. 找出不同的二进制字符串](https://leetcode.cn/problems/find-unique-binary-string/description/)

## 题目描述

给定一个长度为 `n` 的二进制字符串数组 `nums`，其中每个字符串都是**长度为 `n`** 的二进制串（只包含 `'0'` 和 `'1'`）。

返回**任意一个**长度为 `n` 的二进制字符串，使其**不在** `nums` 中。

**示例 1**：
```
输入：nums = ["01","10"]
输出："11"
解释："11" 不在 nums 中
```

**示例 2**：
```
输入：nums = ["00","01"]
输出："10" 或 "11"
```

**示例 3**：
```
输入：nums = ["111","011","001"]
输出："101"
```

**约束条件**：
- `1 <= n <= 16`
- `nums[i].length == n`
- `nums[i]` 只包含 `'0'` 或 `'1'`
- `nums` 中的所有字符串都是唯一的

---

# 思路一：哈希表 + 枚举

## 解题思路

**核心思想**：将所有字符串存入哈希表，然后枚举所有可能的 `n` 位二进制串，返回第一个不在哈希表中的串。

这是我最自然的想法：题目要求找一个"不在给定集合中"的二进制串，最直接的方法就是：
1. 把所有给定的串存起来（方便快速查找）
2. 从 $0$ 到 $2^n - 1$ 逐个检查，看哪个对应的二进制串不在集合中
3. 然后由于 $n < 2^n$，所以必有缺失的串。我们只需要枚举 $0$ 到 $n$（共 $n+1$ 个），根据鸽巢原理必有至少一个缺失。

**算法流程**：
1. 将 `nums` 中的所有字符串存入 `unordered_set`
2. 枚举整数 `i` 从 $0$ 到 $n$（注意：只需要枚举 $n+1$ 个数！）
3. 将每个 `i` 转换为 `n` 位二进制字符串
4. 检查该字符串是否在哈希表中
5. 返回第一个不在哈希表中的字符串

**关键优化点**：
- **鸽巢原理**：数组中只有 `n` 个元素，我们枚举 `n+1` 个候选（`0` 到 `n`），必有至少一个缺失
- **不需要**枚举所有 `2^n` 个二进制串，只需要枚举 `n+1` 个！
- 这将时间复杂度从理论上的 $O(2^n \times n)$ 优化到实际的 $O(n^2)$

**关键实现细节**：
- 整数转二进制字符串：从低位到高位检查每个 bit，从字符串末尾开始填充
- 哈希表使用 `unordered_set<string>`，默认哈希函数即可（不需要自定义）

## 复杂度

- **时间复杂度**：$O(n^2)$
  - 构建哈希表：$O(n)$ 个串，每个串 $O(n)$ 哈希计算
  - 枚举检查：$O(n)$ 个候选串（`0` 到 `n`），每个串 $O(n)$ 哈希查找
  - 总计：$O(n \times n) + O(2n) = O(n^2)$

- **空间复杂度**：$O(n^{2})$
  - 哈希表存储 $n$ 个字符串，每个字符串长度为 $n$

## Code

```cpp
class Solution {
public:
    // 辅助函数：将整数转换为 n 位二进制字符串
    auto to_binary_string(int num, int n) -> string {
        string result(n, '0');
        for (int i = 0; i < n; ++i) {
            if (num & (1 << i)) {
                result[n - 1 - i] = '1';  // 从低位到高位填充
            }
        }
        return result;
    }

    string findDifferentBinaryString(vector<string>& nums) {
        // 将所有字符串存入哈希表
        unordered_set<string> sets(nums.begin(), nums.end());

        int n = nums.size();
        // 枚举 0 到 n（共 n+1 个候选），根据鸽巢原理必有缺失
        for (int i = 0; i <= n; ++i) {
            string s = to_binary_string(i, n);
            if (sets.find(s) == sets.end()) {
                return s;  // 找到第一个不在集合中的串
            }
        }
        return "";  // 理论上不会执行到这里
    }
};
```

**问题/优化方向**：
- ✅ 代码简洁清晰，容易理解
- ✅ 时间复杂度可接受（$n \le 16$）
- ❌ 没有利用题目特性，存在优化空间（可以做到 $O(n)$）

# 思路二：对角线构造（✅ 推荐解法）

## 解题思路

**核心思想**：利用鸽巢原理，构造一个与所有给定串都不同的二进制串。

这是在讨论优化时发现的巧妙方法：
- 我说："哈希表解法能过，但没加分"
- 进一步思考：**鸽巢原理**告诉我们，$n$ 个 $n$ 位二进制串，必有至少一个缺失
- 关键洞察：如何**构造性地**找到一个缺失串？

**构造方法**：
- 对于第 `i` 个字符串 `nums[i]`，让答案的第 `i` 位与 `nums[i][i]` 不同
- 即：`ans[i] = (nums[i][i] == '0' ? '1' : '0')`

**为什么正确？**
- 假设构造的 `ans` 在 `nums` 中，设 `ans = nums[k]`
- 但根据构造规则，`ans[k] != nums[k][k]`，矛盾！
- 因此 `ans` 必不在 `nums` 中

**算法流程**：
1. 初始化空字符串 `ans`
2. 遍历 `i` 从 `0` 到 `n-1`
3. 对于每个 `i`，检查 `nums[i][i]`：
   - 如果是 `'0'`，则 `ans += '1'`
   - 如果是 `'1'`，则 `ans += '0'`
4. 返回 `ans`

## 复杂度

- **时间复杂度**：$O(n)$
  - 只需遍历一次数组，每个位置 $O(1)$ 判断

- **空间复杂度**：$O(1)$
  - 只需要常数空间存储答案字符串（不计输出）

## Code

```cpp
class Solution {
public:
    string findDifferentBinaryString(vector<string>& nums) {
        string ans;
        for (int i = 0; i < nums.size(); ++i) {
            // 构造第 i 位：与 nums[i][i] 不同
            ans += (nums[i][i] == '0' ? '1' : '0');
        }
        return ans;
    }
};
```

**问题/优化方向**：
- ✅ 时间复杂度最优：$O(n)$
- ✅ 空间复杂度最优：$O(1)$
- ✅ 代码极其简洁，体现数学思维
- ⚠️ 需要理解鸽巢原理和构造性证明

# 关键词与核心洞察

## 关键词

- **鸽巢原理**：$n$ 个鸽子（$n$ 位二进制串）放入 $2^n$ 个巢（所有可能的串），必有空巢
- **构造性证明**：不是"存在性证明"，而是直接构造出解
- **对角线方法**：经典的构造技巧（类似 Cantor 对角线论证）
- **哈希表优化**：从暴力枚举到哈希表查找，体现"空间换时间"思想

## 本题 Insight

- **对角线构造的本质**：不是"碰运气"，而是**系统性**地确保与每个给定串至少有一位不同
  - 第 `i` 位确保与 `nums[i]` 不同
  - 因此不可能等于任何一个 `nums[i]`

- **鸽巢原理的威力**：
  - 不需要枚举所有 $2^n$ 个串
  - 只需构造一个，就能保证它不在集合中
  - 这是"存在性"到"构造性"的跨越

- **面试策略**：
  - 先写哈希表解法（保证正确性，展示基础）
  - 再说"可以优化到 $O(n)$"（展示思维深度）
  - 这样既稳健又有亮点

## 易错点

1. **枚举范围的边界**
   - ✅ 正确：`for (int i = 0; i <= n; ++i)`（枚举 $n+1$ 个，鸽巢原理保证）
   - ❌ 错误：`for (int i = 0; i < n; ++i)`（只枚举 $n$ 个，可能不够）
   - **原因**：数组中有 $n$ 个元素，必须枚举 $n+1$ 个候选才能保证必有缺失

2. **避免不必要的枚举**
   - ✅ 正确：`for (int i = 0; i <= n; ++i)`（只需枚举 $n+1$ 个，鸽巢原理）
   - ❌ 错误：`for (int i = 0; i < (1 << n); ++i)`（枚举 $2^n$ 个，不必要）

3. **哈希表构造函数参数**
   - ✅ 正确：`unordered_set<string> sets(nums.begin(), nums.end())`（使用默认参数）
   - ❌ 错误：`unordered_set<string> sets(nums.begin(), nums.end(), nums.size())`（参数顺序错误）

4. **自定义哈希函数的返回类型**
   - ✅ 正确：`-> size_t` 显式声明返回类型，函数体末尾 `return result`
   - ❌ 错误：lambda 没有 `return`，返回 `void`

# 扩展思考

## Q1：为什么 $n$ 个 $n$ 位二进制串必有缺失？

**答**：鸽巢原理。
- 所有可能的 $n$ 位二进制串共有 $2^n$ 个
- 给定 $n$ 个串，$n < 2^n$（当 $n \ge 1$ 时）
- 因此至少有 $2^n - n \ge 1$ 个串不在集合中

## Q2：对角线构造的答案唯一吗？

**答**：不唯一。
- 对角线构造只是**一种**方法
- 任何不在 `nums` 中的串都是合法答案
- 例如：`nums = ["01", "10"]`，合法答案有 `"00"` 和 `"11"`

## Q3：为什么只需要枚举 `0` 到 `n`，而不是 `0` 到 `2^n - 1`？

**答**：鸽巢原理。
- 数组中只有 `n` 个元素
- 我们枚举 `n+1` 个候选（`0` 到 `n`）
- 根据鸽巢原理，必有至少一个候选不在数组中
- 这将时间复杂度从 $O(2^n \times n)$ 降低到 $O(n^2)$

**示例**：
- `n = 2`，`nums = ["01", "10"]`
- 枚举 `0, 1, 2`（3个候选），对应 `"00", "01", "10"`
- `"00"` 不在 `nums` 中，直接返回
- **不需要**枚举 `"11"`（虽然它也是合法答案）

## Q4：如果 $n$ 很大（如 $n = 10^5$），哈希表解法还能用吗？

**答**：不能。
- 哈希表解法需要枚举 $2^n$ 个串，当 $n$ 很大时不可行
- 但对角线构造仍然是 $O(n)$，不受 $n$ 大小影响
- 这体现了构造性方法的威力

## Q4：如何证明对角线构造的正确性？

**答**：反证法。
- 假设构造的 `ans` 在 `nums` 中，设 `ans = nums[k]`
- 根据构造规则，`ans[k] != nums[k][k]`
- 矛盾！因此 `ans` 不可能在 `nums` 中
